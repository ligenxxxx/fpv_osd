use samba+vscode to edit source code
use ssh to connect pi and run app

- connect wifi
    sudo nmtui
    activate a connection -> edit a connection
    enter passwd and connect

- open ssh server
    sudo systemctl start ssh
    sudo systemctl enable ssh

- get ip
    ifconfig
    my pi's ip is 192.168.10.8

- connect pi to your pc with ssh
    ping 192.168.10.8
    ssh gli@192.168.10.8

- install environment at pi
    sudo apt update
    apt list --upgradable
    sudo apt install -y vim build-essential cmake gcc gdb samba libcamera-dev libdrm-tests libdrm-dev git

- open Serial Port at pi
    sudo raspi-config
    Interface Options -> Serial Port -> login No -> hardware Yes
    Finish -> reboot Yes

- config samba at pi
    make -p ~/prj
    sudo vi /etc/samba/smb.conf
    add following at the end:
    [prj]
       path = /home/gli/prj
       browseable = yes
       writeable = yes
       create mask = 0775
       directory mask = 0775
       public = no
       valid users = gli
       
       change notify = yes
       stat cache = no
       directory name cache = no

       oplocks = no
       level2 oplocks = no

- set samba passwd at pi
    sudo smbpasswd -a gli

- enable samba at pi
    sudo systemctl restart smbd
    sudo systemctl enable smbd

- map prj folder at your pc
    win+e to open computer
    ...(upper) -> Map Network Drive -> \\192.168.10.8\prj

- config git at pi
    git config --global user.name "yourname"
    git config --global user.email "yourmail"
    git config --global init.defaultBranch main

- config git ssh at pi
    ssh-keygen -t rsa -C "yourmail"
    - open https://github.com/settings/ssh/new
    - enter SSH and GPG keys
    - enter New SSH key
    - name title
    - copy /home/gli/.ssh/id_ras.pub data to Key
    - add SSH key

- disable filemode at your pc
    git config core.filemode false
